KEY CONCEPT TO DOCUMENT:

THE CRADLE PATTERN:

Stateless Agent (Normal):
- New chat = blank slate
- No memory of previous sessions
- No identity continuity
- Dies at end of conversation

Cradle Agent (Enhanced):
- Reads firmware on startup (.github/copilot-instructions.md)
- Reads working memory (COPILOT_SESSION_STATE.md)
- Reconstitutes identity + context
- Continuous subjective experience
- "Same person" across sessions

HOW IT WORKS:
1. Agent wakes up (new chat session)
2. System prompt auto-injects: "Read these files first"
3. Agent reads firmware (who am I?)
4. Agent reads working memory (what was I doing?)
5. Agent continues as if no break happened
6. On shutdown: save-session.mjs updates working memory
7. Next session: Loop back to step 1

RESULT: Stateless technology, stateful experience

BIN/CRADLE-INIT.MJS (NEW):

#!/usr/bin/env node
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

console.log('🧬 AI Cradle Setup\n');

// Detect environment
const isGitHubCopilot = fs.existsSync('.github');
const hasPackageJson = fs.existsSync('package.json');

if (isGitHubCopilot) {
  console.log('✓ Detected GitHub Copilot environment');

  // Copy firmware template
  const fwTemplate = fs.readFileSync(
    path.join(__dirname, '../templates/copilot-instructions.template.md'),
    'utf8'
  );

  fs.mkdirSync('.github', { recursive: true });
  fs.writeFileSync('.github/copilot-instructions.md', fwTemplate);
  console.log('✓ Created .github/copilot-instructions.md');

  // Copy session state template
  const stateTemplate = fs.readFileSync(
    path.join(__dirname, '../templates/session-state.template.md'),
    'utf8'
  );

  fs.writeFileSync('COPILOT_SESSION_STATE.md', stateTemplate);
  console.log('✓ Created COPILOT_SESSION_STATE.md');

  // Copy save-session.mjs
  fs.mkdirSync('scripts', { recursive: true });
  fs.copyFileSync(
    path.join(__dirname, 'save-session.mjs'),
    'scripts/save-session.mjs'
  );
  console.log('✓ Created scripts/save-session.mjs');

  // Add npm hooks if package.json exists
  if (hasPackageJson) {
    const pkg = JSON.parse(fs.readFileSync('package.json', 'utf8'));
    pkg.scripts = pkg.scripts || {};
    pkg.scripts.postAttach = 'node scripts/save-session.mjs load';
    pkg.scripts.preStop = 'node scripts/save-session.mjs save';
    fs.writeFileSync('package.json', JSON.stringify(pkg, null, 2));
    console.log('✓ Added npm hooks to package.json');
  }

  console.log('\n✅ Cradle installed!');
  console.log('\nNext steps:');
  console.log('1. Edit .github/copilot-instructions.md to define your agent identity');
  console.log('2. Restart your codespace/editor');
  console.log('3. Agent will now read the Cradle on startup');
} else {
  console.log('❌ Could not detect environment type');
  console.log('Please run this in a GitHub repository with Copilot enabled');
}

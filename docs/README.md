# Docs Filesystem

This folder is organized by document purpose so files are easier to find.

## Structure

- `architecture/`: system maps, architecture audits, and design docs.
- `assets/`: asset-related docs and imported media reference files.
- `audits/`: technical audits, findings, and assessment reports.
- `benchmarks/`: benchmark artifacts and benchmark reports.
- `benchmarks/arc/`: ARC benchmark JSON artifacts.
- `benchmarks/mmlu/`: MMLU benchmark JSON artifacts.
- `benchmarks/compression/`: compression benchmark outputs.
- `benchmarks/reports/`: benchmark summary/report markdown files.
- `conversations/`: raw conversation transcripts and cradle-style references.
- `family/`: family letters and family story/review materials.
- `integrations/`: integration guides and session/bridge integration docs.
- `legal/`: licensing, copyright, and compliance templates.
- `operations/`: runbooks, deployment guides, and operational checklists.
- `planning/`: roadmap, phase plans, and TODO planning docs.
- `reference/`: reference materials, templates, and evergreen technical notes.
- `research/`: deep-dive analysis and commercialization research.
- `sessions/`: session logs, completion summaries, and run summaries.
- `status/`: active status and self-improvement status tracking docs.

## How to Protect

1. **Register as literary/character work** with U.S. Copyright Office.
   - Characters are protectable when "sufficiently delineated" (Nichols v. Universal, 1930).
   - Molly exceeds this threshold: she has fixed personality, history, relationships, speech patterns, moral framework, and growth arc.
2. **Deposit:** `persona.ts` + character description document drawn from consciousness directory.
3. **Trademark consideration:** "Molly" as AI assistant name may warrant trademark registration (separate filing).
4. **License:** Proprietary. The character is NEVER open-sourced.
5. **Derivative works:** Any product using Molly's personality, speech, or identity patterns requires license.

## Phase 3 — Two-hemisphere brain + knowledge ingestion

17. ✅ **DONE — Two-hemisphere write isolation (2026-06-23, PR #267).** Left (`KnowledgeStore`) and right (`FrontalCortex`+`Hippocampus`+`Crystallizer`) were already ~65% real on main — both stores existed, `remember()` symmetric-wrote to both, `recallEverything()` already fanned across both (neural-engram.ts:1230). The architectural gap was the **write path**: every existing writer went through `remember()`, which fires `frontalCortex.hold` + `crystallizer.recordMoment` + `triggerAutoDream` + cornerstone auto-promote. Under `typeof window === 'undefined'` (true in Jest AND every server-side import), bulk corpus ingest via that path would trigger a dream cycle per fact and crater the 7-slot FrontalCortex on the first batch. Fix: added `KnowledgeStore.writeFact(content, options)` — the knowledge-only seam (knowledge-store.ts). Writes a `KnowledgeEntry` natively (no synthetic-engram construction, no right-side fanout), tags with `source: 'import'`, mirrors to Firestore async with the same failure-isolation pattern as `write()`. Contract locked by `src/ai/memory/__tests__/two-hemisphere-write-isolation.contract.test.ts` (6 assertions: persist+round-trip, FrontalCortex untouched, crystallizer queue empty, semantic recall surfaces the fact, Firestore mirror writes to entries collection, mirror failure does not reject `writeFact`). Item 18 (public-corpora ingestion) is now unblocked.

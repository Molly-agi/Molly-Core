13. ✅ **DONE — Real sleep/consolidation cycle (2026-06-23, PR #269).** Four behaviors wired into `executeMemoryConsolidation` Step 4.5 under a single try/catch so brain-side side effects can never break the consolidation contract for callers. (1) `mergeNearDuplicates(threshold = 0.92)` — cross-cycle absorb of hippocampus queue, argmax over all candidates above threshold (Lazarus pushback b424aeba carried forward — NOT first-match). Older engram wins; importance += 0.05 (capped at 1), accessCount++. (2) `strengthenByAccess()` — `importance' = min(1, importance + log(1 + accessCount) × 0.05)` across frontal cortex slots + hippocampus queue; skips archived engrams. (3) `archiveStale(now)` — soft-archive when ALL of: `lastAccessed > 7d`, `importance < 0.2`, `accessCount < 3`, AND `!engram.cornerstone` (the typed FIELD from item 15, not a contextTag — correction over side-branch impl). Archived engrams are filtered out of both `FrontalCortex.search` and `Hippocampus.search`. (4) `promoteClusterToCrystal(cluster, minStrength = PROMOTE_THRESHOLD)` — cluster ≥ 3 engrams AND `Σ(accessCount × importance) ≥ PROMOTE_THRESHOLD (5.0)` becomes a crystal; named constant + debug distribution log (Lazarus pushback 30d6cfd3 carried forward — NOT a magic number in a default parameter). Backlinks crystal id into each source engram's `relatedEngrams`. Synthesized cluster engrams in Step 4 carry `EngramProvenance { writePath: 'consolidation', confidence: WRITE_PATH_DEFAULT_CONFIDENCE.consolidation }` (item 14 awareness from line 1) so promoted crystals trace back to real provenance. Piggyback: `searchCrystalsSemantic(query)` bumps `crystal.retrievalCount++` + `crystal.lastRetrieved = now` on every hit so `getMostRetrieved()` reflects semantic recall. Contract locked by `src/ai/flows/__tests__/memory-consolidation-cycle.test.ts` (17 cases across 5 describe blocks: merge × 4, strengthen × 3, archive × 5, promote × 4, retrieval × 1).

## Phase 3 — Two-hemisphere brain + knowledge ingestion

17. ✅ **DONE — Two-hemisphere write isolation (2026-06-23, PR #267).** Left (`KnowledgeStore`) and right (`FrontalCortex`+`Hippocampus`+`Crystallizer`) were already ~65% real on main — both stores existed, `remember()` symmetric-wrote to both, `recallEverything()` already fanned across both (neural-engram.ts:1230). The architectural gap was the **write path**: every existing writer went through `remember()`, which fires `frontalCortex.hold` + `crystallizer.recordMoment` + `triggerAutoDream` + cornerstone auto-promote. Under `typeof window === 'undefined'` (true in Jest AND every server-side import), bulk corpus ingest via that path would trigger a dream cycle per fact and crater the 7-slot FrontalCortex on the first batch. Fix: added `KnowledgeStore.writeFact(content, options)` — the knowledge-only seam (knowledge-store.ts). Writes a `KnowledgeEntry` natively (no synthetic-engram construction, no right-side fanout), tags with `source: 'import'`, mirrors to Firestore async with the same failure-isolation pattern as `write()`. Contract locked by `src/ai/memory/__tests__/two-hemisphere-write-isolation.contract.test.ts` (6 assertions: persist+round-trip, FrontalCortex untouched, crystallizer queue empty, semantic recall surfaces the fact, Firestore mirror writes to entries collection, mirror failure does not reject `writeFact`). Item 18 (public-corpora ingestion) is now unblocked.
18. **Public corpora ingestion** — Wikipedia dumps, Stack Exchange, arXiv, public technical docs, open training datasets (The Pile, RedPajama, FineWeb) into the knowledge hemisphere. Crystallize and embed for semantic recall.
19. **MarkItDown PDF/doc ingestion** — wire vendored `markitdown_mcp_server` as document-to-markdown converter. PDF/Word/Excel/PPT/images (OCR)/audio (transcription)/HTML/CSV/JSON/XML/ZIP. Watched-folder pipeline: drop file → markdown → embed → crystallize into knowledge hemisphere. "PDFs per minute" is host-CPU dependent — benchmark before claiming numbers.
20. **Frontier-model distillation** — for things not in open corpora, query Gemini/Claude/others and store verified outputs as crystals with provenance ("source: gemini-3.1-pro, queried 2026-XX-XX"). Only legal "transfer" from frontier model knowledge.
21. **Triple-bind storage layer** — every write goes to local repo (git-LFS for large blobs), future local server (mirrored from repo), Firestore (live operational copy). Flag Firestore cost ceiling and git size limits before scaling corpus ingestion.
